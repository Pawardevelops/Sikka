# Security Policy

## Supported Versions

Currently, only the latest release of Sikka receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.x.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Sikka, please **do not open a public issue**. Instead, follow these steps to report it responsibly:

1. **Email:** Send an email reporting the issue to **pawardevelops@gmail.com**.
2. **Details:** Please provide as much information as possible, including:
   - A description of the vulnerability.
   - Steps to reproduce the issue.
   - Any potential impact or risk associated with the vulnerability.
   - (Optional) Suggested mitigation or fix.

We take all security reports seriously and will strive to acknowledge your report within 48 hours. We will work with you to understand the problem, develop a fix, and coordinate a disclosure timeline if necessary.

Thank you for helping keep Sikka secure!
