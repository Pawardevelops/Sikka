# LottieMotion

The eight Lottie animations, playing live from `assets/Motion`. Use lottie-web on the web and lottie-react-native in the app.

- Loops: sikku-bounce, listening-pulse, streak-flame, loading-coins.
- One-shots: success-check, confetti-burst, coin-drop, card-swipe-approve. Play once, hold the last frame.
- Reduced motion: show the last frame, do not play.
