# IconButton

A round 44 px button with only an icon, for back, close, edit and the mic.

- Always give it an `aria-label`.
- `sk-icon-btn--lime` for voice and add; `sk-icon-btn--night` for the strongest action in a cluster (approve in the deck).
- `sk-icon-btn--xl` (72 px) with its lime halo is the deck's approve button and the stop-recording button.
