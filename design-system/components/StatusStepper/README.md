# StatusStepper

The life of a payment in four steps: Captured → Place → Name it → Done. Also used for a subscription cycle.

- Done steps: night dot with a lime check. The current step: signal orange with a soft halo that pulses. Future steps: dashed outline.
- Always show the words, not only the dots.
- When a step completes, its dot pops (`sk-pop`) and the link turns ink.
