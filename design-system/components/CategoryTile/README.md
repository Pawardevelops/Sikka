# CategoryTile

A pastel square with a category icon and label. Used to pick a category in review, add-by-hand and the payment notification.

- Group them in a 4-column grid with `space-2` gaps, inside `role="radiogroup"`.
- The selected tile gets a 3 px ink ring and a night check badge in its corner.
- Press shrinks to 0.94 and springs back.
