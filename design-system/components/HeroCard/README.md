# HeroCard

The one big block per screen: a pastel (or lime, or night) card with an overline and the number that matters in `amount-xl`.

- Default is lime (net worth). Add a category class for others: butter for an amount being typed, pink for a card, mint for backup.
- One decorative white circle bleeds off the top-right corner. Nothing else decorates it.
- Its number counts up over `dur-slow` when the screen opens.
