# TabBar

A white floating pill with five places: Home, Review, the raised mic, Stats, Assets.

- The active tab grows into a lime pill with its label. Others are icon-only with `aria-label`.
- The review tab carries a signal badge with the count; it pops when the count changes.
- The mic is always the centre, raised 34 px with a ground-coloured ring so it reads as a cut-out.
