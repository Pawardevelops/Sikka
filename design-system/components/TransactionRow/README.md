# TransactionRow

One payment: a category icon tile, the payee, a meta line, the amount in the display face and an optional mood face.

- Money out is ink with a true minus `−₹`. Money in uses `sk-row__amount--in` (lime-deep) with `+₹`.
- Meta line: a voice note in quotes, or place · time. It truncates with an ellipsis.
- Rows enter with `sk-rise`, staggered by `--i`.
