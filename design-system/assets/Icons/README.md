# Icons

41 line icons, 24 × 24, 2 px stroke, round caps and joins, drawn in ink `#1D1B16`. Navigation, actions, categories (dining, groceries, transport, shopping, fun, bills, health) and accounts (bank, cash, card, wallet, trending-up). Recolour in code with a CSS mask or by inlining the path with `stroke="currentColor"`.
