# Motion

Eight Lottie (Bodymovin 5.7) animations, 200 × 200 at 60 fps, vector only, colours from the tokens: sikku-bounce, listening-pulse, success-check, confetti-burst, coin-drop, card-swipe-approve, streak-flame, loading-coins. Play with lottie-web on the web or lottie-react-native in the app. Where and how long each plays: the Motion section of the brand book.
