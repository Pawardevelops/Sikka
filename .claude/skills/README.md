# Product skills for Sikka

Six product-team skills for Claude Code, copied from
[borghei/Claude-Skills · product-team](https://github.com/borghei/Claude-Skills/tree/main/product-team) (MIT license, © borghei).

| Skill | Use it for |
|---|---|
| `product-manager-toolkit` | RICE prioritisation, interview analysis, PRDs |
| `product-designer` | Journey maps, usability (SUS) scoring, design decisions |
| `ux-researcher-designer` | Personas, journey maps, research plans |
| `design-system-lead` | Tokens, component library, design-system governance |
| `product-analytics` | Metrics, event tracking plan, funnels |
| `spec-to-repo` | Turn a PRD / user stories into a repo plan |

Claude Code loads skills from `.claude/skills/` when you open this repo. The Python helpers in each `scripts/` folder use only the standard library.

Not included from the source folder: ab-test-setup, agile-product-owner, apple-hig-expert, design-direction, product-strategist, research-summarizer, roadmap-communicator, ui-design-system.
